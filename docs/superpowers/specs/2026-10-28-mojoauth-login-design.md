# MojoAuth merchant login

Continue the user's MojoAuth setup by connecting the merchant dashboard to hosted sign-in. Keep the existing dashboard, storage and customer capability links. Customer history remains a labeled demo; this does not authenticate receipt visitors or link customer accounts.

Use server-side OIDC Authorization Code with PKCE S256, state and nonce. GET `/api/auth/mojo/login` starts login. GET `/api/auth/mojo/callback` exchanges the code, verifies the signed ID token and nonce, creates the existing eight-hour HttpOnly session, and redirects to `/`. A ten-minute encrypted HttpOnly transaction cookie holds the verifier and binds the callback to the browser, issuer, client and origin. Never persist provider tokens in browser storage. Failed callbacks clear the transaction and return a safe error in the dashboard, without provider errors, codes or tokens in the redirect.

Use discovery from the configured issuer, validating issuer and HTTPS endpoints against the same origin and configured JWKS. Follow the discovered token endpoint rather than guessing `/oauth/token` vs `/oauth2/token`. Server authentication needs `MOJOAUTH_CLIENT_SECRET`; `MOJOAUTH_AUDIENCE` is the client ID. A public GET `/api/auth/config` reports readiness only. Login endpoints run before storage initialization. Existing Supabase login and platform identity remain supported; prefer MojoAuth in the login UI when ready. Authenticated users must be able to end their RingOrden session. An identity from a new provider must not silently inherit an existing merchant's data based on email.

Reject missing/mismatched/expired state, malformed discovery, wrong nonce, invalid signature, issuer or audience, and unsupported methods. Restrict logout to same-origin POST. Do not leak client secrets or expose privileged merchant routes through a public provider ingress. No dependency additions. No deployment, provider settings changes or credential rotation in this source change. Document the exact callback and missing configuration for the user.
